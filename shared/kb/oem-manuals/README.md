# OEM equipment manuals

This folder grounds the plant **maintenance** agent's knowledge base (see the
`maintenance` document source in each plant's `profile.yaml`).

The original manuals are **third-party, copyrighted OEM documents** and are **not
redistributed** in this repository. To run the maintenance scenarios with real
grounding, place the relevant PDF manuals for your equipment here, for example:

- `Fanuc Robot LR Mate 200iD Operators Manual.pdf`
- `HAAS-cnc-mill-manual.pdf`

PDFs in this folder are git-ignored (see [`.gitignore`](../../../.gitignore)),
so your local copies stay out of version control.
