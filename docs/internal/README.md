# Internal working docs

These are **build-tracking artifacts** kept for provenance — they are **not**
required to run or understand the demo. Start with the top-level
[`README.md`](../../README.md) and [`docs/SOLUTION_ARCHITECTURE.md`](../SOLUTION_ARCHITECTURE.md)
instead.

Contents:

- `DEMO_BUILD_HANDOFF.md` — the original design/build handoff.
- `plans/` — per-gate implementation plans (A/B/C/D).
- `specs/` — gate status snapshots and design addenda.
- `results/` — gate completion results.

> **Note:** Some path references inside these historical documents were written
> against the original repository layout (before this folder existed) and may
> point to `docs/plans/…`, `docs/specs/…`, or `docs/results/…`. Those files now
> live under `docs/internal/…`.
