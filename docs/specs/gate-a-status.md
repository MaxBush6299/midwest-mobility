- **Infra (Bicep, `rg-magentictest`):** 2 Foundry projects (`mmc-plant`, `mmc-enterprise`) on the *new* Foundry Agent Service, 2 Azure AI Search instances, storage, project→Search connections (Entra-auth), RBAC for project MIs.
- **Knowledge:** Foundry IQ KB `kb-plant7` seeded with 22 docs across 3 sources (plant7 internal, OEM manuals, regulatory reference). Semantic retrieval verified by `scripts/verify_kb_retrieval.py` (rerank scores 2.14–2.25).
- **Portal-managed agents:** 5 Plant 7 prompt agents (`plant7-ehs`, `plant7-maintenance`, `plant7-quality`, `plant7-shiftops`, `plant7-training`) provisioned via `azure-ai-projects 2.2` `AIProjectClient.agents.create_version()` with `PromptAgentDefinition` on `gpt-5.4-mini`. Visible in the standard "Agents" tab (not "Agents (classic)"). The `kb-plant7` Foundry IQ MCP tool is **baked into every version by the factory** via `PLANT_KB_CONNECTION_ID` + `PLANT_KB_MCP_URL` env vars (commit `4410884`) — no portal action required.
- **Supply Chain stub:** Deterministic fixture-backed tools (`erp.bom_where_used`, `supplier.lookup`, `supplier.alternates`) and hand-authored A2A card (`enterprise/supply-chain/agent.json`).
- **Registry:** Local catalog (`agents/catalog.json` auto-generated by `scripts/refresh_catalog.py`); Agent365 stub source for Gate B uplift.
- **Orchestration:** `MagenticBuilder` + `StandardMagenticManager` coordinating the 5 `FoundryAgent` participants. The **manager uses its own deployment** (`FOUNDRY_MANAGER_DEPLOYMENT=gpt-5.4`) so it doesn't share TPM quota with the agents on `gpt-5.4-mini` — this eliminated repeated 429s. Live smoke test (`tests/test_brake_caliper_smoke.py` with `MMC_LIVE=1`) passes — ~200 workflow events, all 5 plant7 agents participate, manager runs with `max_round_count=15` and emits a synthesized final answer via `WorkflowEvent(type='output')`.
- **Tracing:** Wired via `src/mmc_agents/observability.py` (`azure-monitor-opentelemetry` + Agent Framework instrumentation). Spans land in App Insights resource `mmc-plant-appinsights-5430`; the whole run is grouped under the `magentic.scenario.<plant_id>` parent span. Per-agent KB citations are also visible in each Foundry portal agent pane.
- **End-to-end demo runner:** `scripts/run_scenario.py` runs the brake-caliper scenario and prints per-agent KB-grounded answers + the manager's final synthesis to `scenario_out.txt`.
- **Tests:** 10 unit tests + 2 live tests passing (`pytest`).

## Foundry IQ MCP wiring (resolved mid-Gate-A)

The original plan deferred MCP-tool wiring until `azure-ai-agents 2.0` shipped. **This is no longer required:** `azure-ai-projects 2.2.0` `MCPTool(server_label=..., server_url=..., require_approval='never', project_connection_id=...)` works against the new Foundry Agent Service today. The factory uses this and bakes the tool into every agent version. The KB itself must be created with `retrieval_reasoning_effort=KnowledgeRetrievalMinimalReasoningEffort()` (typed class, not the string `"minimal"`) to avoid runtime errors.

## SDK pivot note (mid-Gate-A)

The factory was originally written against the classic `azure-ai-agents` SDK (`cognitiveservices.azure.com` endpoint), which placed agents under "Agents (classic)" in the portal — that path is slated for retirement on 2027-03-31. Mid-Gate-A we deleted those agents and re-provisioned via `azure-ai-projects 2.2` against `services.ai.azure.com`. See commit `f65ed4d` and `docs/specs/2026-06-16-mmc-agent-network-sdk-addendum.md` D20.

## Reproduce

```pwsh
# Provision infra
az deployment group create -g rg-magentictest -f infra/bicep/main.bicep -p @infra/bicep/parameters/dev.bicepparam

# .env must contain (at minimum):
#   FOUNDRY_PLANT_PROJECT_ENDPOINT=https://mmcfdy.services.ai.azure.com/api/projects/mmc-plant
#   FOUNDRY_MODEL_DEPLOYMENT=gpt-5.4-mini
#   FOUNDRY_MANAGER_DEPLOYMENT=gpt-5.4
#   PLANT_KB_CONNECTION_ID=kb-kb-plant7-<suffix>
#   PLANT_KB_MCP_URL=https://srch-mmc-plant.search.windows.net/knowledgebases/kb-plant7/mcp?api-version=2026-05-01-preview
#   APPLICATIONINSIGHTS_CONNECTION_STRING=<from mmc-plant-appinsights-5430>

# Seed KB (sets retrieval_reasoning_effort=minimal)
.\.venv\Scripts\python.exe scripts/seed_foundry_iq.py

# Create/refresh portal agents + cards (bakes KB MCP tool into every version)
.\.venv\Scripts\python.exe scripts/generate_cards.py

# Run smoke (composition bounds only)
$env:MMC_LIVE = "1"
.\.venv\Scripts\python.exe -m pytest tests/test_brake_caliper_smoke.py -v -s

# Run full end-to-end demo with synthesis capture
.\.venv\Scripts\python.exe scripts/run_scenario.py
# Output (per-agent + manager synthesis) appears live and is also written to scenario_out.txt
```
