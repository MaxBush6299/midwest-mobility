## SDK pivot note (mid-Gate-A)

The factory was originally written against the classic `azure-ai-agents` SDK (`cognitiveservices.azure.com` endpoint), which placed agents under "Agents (classic)" in the portal — that path is slated for retirement on 2027-03-31. Mid-Gate-A we deleted those agents and re-provisioned via `azure-ai-projects 2.2` against `services.ai.azure.com`. See commit `f65ed4d` and `docs/specs/2026-06-16-mmc-agent-network-sdk-addendum.md` D20.

## Reproduce

```pwsh
# Provision infra
az deployment group create -g rg-magentictest -f infra/bicep/main.bicep -p @infra/bicep/parameters/dev.bicepparam

# Seed KB
.\.venv\Scripts\python.exe scripts/seed_foundry_iq.py

# Create/refresh portal agents + cards
.\.venv\Scripts\python.exe scripts/generate_cards.py

# Run smoke
$env:MMC_LIVE = "1"
.\.venv\Scripts\python.exe -m pytest tests/test_brake_caliper_smoke.py -v -s
```
